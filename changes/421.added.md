**A runbook and a script prepare each customer's Google Workspace access.** (#421) The owner gets written steps for Atesta's Google Cloud project, including the exemption that allows keys there. A script creates each customer's two read-only service accounts, rotates their keys every 90 days and disables them when the customer disconnects. A new key is only ever written to memory, and the script prints the exact client IDs and scopes to send the customer.
