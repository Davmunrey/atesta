# Self-hosted fonts

Unmodified Latin WOFF2 subsets from Fontsource, package version **5.3.0** for all three.
These files cover Spanish and English. Next.js serves them from the same origin; no runtime
font service or additional package dependency. Sans and display are variable-weight fonts;
mono is regular 400 and is not preloaded. Copyright and OFL-1.1 license text are retained per font.
